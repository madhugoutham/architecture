QUESTION 10

How do filesystem, SSD, CephFS, and object-store tiers affect EPP?

Short answer: EPP can index fs and obj locations from store events and score them — but it never mounts CephFS, inspects SSD directories, or queries object storage at request time. Identity is pod + device tier, not "shared storage domain." Unconfigured tiers fall back to weight 1.0 (like GPU). Store events exist; external deletions often leave stale positives.

🏭
Analogy: warehouse overflow ledgers Each store (pod) keeps a ledger of what it shipped to the regional depot ((pod + tier entry). The depot might be a private shed (local SSD) or a shared warehouse many stores can enter (RWX CephFS) — but the ledger only records the shipper. Sister stores that can grab the same pallet never appear. And if the warehouse throws inventory away without mailing a postcard, the ledger still says the pallet is there.

1 Storage tiers inside the model server

vLLM can offload KV blocks from GPU through CPU staging into a filesystem root or an object store. When events are enabled, successful stores can publish tier-bearing events EPP indexes. EPP scores from that metadata — it does not verify the bytes still exist.

ⓘ Validation playbook
Force a store → prove the model server can reload → observe the event medium → confirm EPP's pod/tier entry → delete via the real retention path → check whether EPP ever learns. For shared FS, read from a non-writing pod. For local SSD, reschedule the pod. For object store, test expiry, credential loss, and throttling. No universal weight without measured workload data.

Key takeaways

  • EPP indexes FS/object tiers from events — it does not mount or probe storage at score time.
  • Identity is pod + device tier; shared CephFS readership is not expanded from one writer's event.
  • Inspected managers emit stores; external deletes often leave stale positives.
  • Unconfigured tiers get weight 1.0 — configure fs/obj deliberately.
  • Fixed per-block weights don't model bandwidth, congestion, or cross-zone cost — measure before shipping.
